# danielhallbro.github.io

Personal portfolio — **[danielhallbro.github.io](https://danielhallbro.github.io)**

## Stack

- [Astro](https://astro.build) — static site generator
- Vanilla CSS — no frameworks
- Markdown — content for projects and blog posts
- Deployed via GitHub Pages

## Development

```bash
npm install
npm run dev
```

## Structure

```
src/
  pages/          # Routes (index, projects, blog)
  content/
    projects/     # Project markdown files
    blog/         # Blog post markdown files
```
